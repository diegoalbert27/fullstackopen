# Full Stack Open — Ejercicios resueltos

Soluciones a los ejercicios de [Full Stack Open](https://fullstackopen.com/), el curso online gratuito de desarrollo web full stack con JavaScript de la Universidad de Helsinki.

**Certificado:** [Ver credencial](https://studies.cs.helsinki.fi/stats/api/certificate/fullstackopen/en/d987a7a3d60e4bbb5903af5da20cff04) · Completado en [2021]

## Contenido del repositorio

| Carpeta | Parte del curso | Qué se trabaja |
|---|---|---|
| `part0` | Fundamentos de las aplicaciones web | Cómo funciona una aplicación web: HTTP, herramientas de desarrollo del navegador, SPA vs. aplicación tradicional |
| `part1` | Introducción a React | Componentes, props, estado, hooks y manejo de eventos |
| `part2` | Comunicación con el servidor | Renderizado de colecciones, formularios, consumo de una API REST y estilos |

> [ELIGE UNA Y BORRA ESTA LÍNEA]
> **Opción A:** Las partes 3 en adelante (Node.js y Express, MongoDB, pruebas, etc.) las completé para obtener el certificado y están en [ENLACE AL REPO].
> **Opción B:** Este repositorio contiene las partes 0 a 2. Las partes siguientes se completaron para obtener el certificado pero no están publicadas aquí.

## Tecnologías

JavaScript · React · HTML · CSS

## Cómo ejecutar un ejercicio

Cada ejercicio de las partes 1 y 2 es una aplicación React independiente:

```bash
git clone https://github.com/diegoalbert27/fullstackopen.git
cd fullstackopen/part1/<ejercicio>
npm install
npm start
```

## Sobre el curso

[Full Stack Open](https://fullstackopen.com/) es un curso de la Universidad de Helsinki que cubre desarrollo web moderno con JavaScript, de React en el frontend a Node.js en el backend, pasando por bases de datos y pruebas. Los ejercicios de este repositorio son mi práctica del curso.
